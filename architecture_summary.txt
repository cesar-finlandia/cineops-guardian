This project assembles 7 chassis component(s) — resilience, platform, ideation, context, data, cost, provenance — on chassis v0.0.0-. resilience provides Generic `withResilience` wrapper + `DegradedResult` + golden cache; platform provides One-command deploy, typed streaming bus, 3 distinct UI themes; ideation provides PIT deck skeleton, IDEA worksheet, RETRO template + 4 Hour 48–72 auto-populators `ideation/deckgen/script/demodrive/faqdef`; context provides Provider-agnostic message buffer + pluggable token counter; data provides On-demand synthetic data generation with `synthetic:true` marker; cost provides Token/request metering + budget warnings, reuses `CTX-02` counter; provenance provides Disclosure generator (`prov`) + submission formatter + repo hygiene guard (`submit`).
